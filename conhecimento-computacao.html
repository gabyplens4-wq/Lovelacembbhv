O que é um algoritmo?

Um algoritmo é uma sequência finita e ordenada de passos para resolver um problema. Uma receita de bolo é um bom exemplo: ela diz quais ingredientes usar, em que ordem misturar e quando levar ao forno. Em matemática, um algoritmo clássico é o método da divisão que aprendemos na escola.

Um bom algoritmo precisa ser claro (cada passo é entendido sem dúvida), finito (chega ao fim) e correto (leva ao resultado esperado).

O que é programação?

Programar é escrever algoritmos em uma linguagem que um computador consiga interpretar. O texto resultante se chama programa. As linguagens de programação são formas organizadas de dar ordens: repetir uma tarefa, tomar uma decisão com base em uma condição, guardar um valor para usar depois.

  • Sequência: executar os passos um após o outro;
  • Repetição: refazer uma etapa várias vezes (um laço);
  • Decisão: escolher um caminho conforme uma condição;
  • Variáveis: guardar valores que mudam durante a execução.

A Máquina Analítica

Projetada por Charles Babbage a partir de 1837, a Máquina Analítica foi pensada como uma máquina de uso geral. Ela teria cartões perfurados para receber instruções, um “armazém” para guardar números (a memória) e um “moinho” para fazer as contas (o processador). Mesmo sem ter sido construída em vida, o projeto tem a mesma lógica geral dos computadores atuais: entrada, memória, processamento e saída.

A importância de Ada Lovelace

Em 1843, Ada publicou notas que explicavam, passo a passo, como a Máquina Analítica poderia calcular números de Bernoulli. Esse conjunto de operações, com ordem, repetição e uso de variáveis, é frequentemente considerado um dos primeiros algoritmos publicados para ser processado por uma máquina.

Mais importante ainda foi a visão de que a máquina poderia trabalhar com símbolos em geral, e não só com números. Essa ideia está na base dos computadores de hoje, que processam texto, imagem, som e vídeo.

Experimente em casa
